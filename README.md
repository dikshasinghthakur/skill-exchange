# SkillSwap - Local Skill Exchange Platform

A modern, interactive platform for local communities to exchange skills and knowledge. Connect with people in your area to teach and learn new skills through bartering or paid sessions.

## ✨ Features

- **Skill Discovery**: Browse skills by categories (Cooking, Music, Coding, Languages, Fitness, etc.)
- **Smart Matchmaking**: AI-powered matching system to find perfect skill exchange partners
- **User Profiles**: Detailed profiles with skills offered/wanted, ratings, and reviews
- **Messaging System**: Built-in chat for coordinating skill exchanges
- **Booking Management**: Schedule and manage skill exchange sessions
- **Safety Guidelines**: Comprehensive safety guide for secure exchanges
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Professional Animations**: Smooth, modern animations for enhanced user experience

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/skill-exchange.git
```

2. Navigate to the project directory:
```bash
cd skill-exchange
```

3. Open `index.html` in your browser or use a local server:
```bash
# Using Python (if installed)
python -m http.server 8000

# Or using Node.js (if installed)
npx serve .

# Or simply open index.html in your browser
```
